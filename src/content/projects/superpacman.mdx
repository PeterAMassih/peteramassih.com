Pac-Man clone in Java, built on top of a hand-written 2D game engine. Six engine layers: math (vectors, transforms), window (Swing), IO (sprites and audio), a signal framework (logic signals for keypresses, wave signals for events), an actor system, and an area-game framework for tile-based worlds with collision and movement. On top, an RPG layer adds inventory and dialogue, and the super-pacman game adds ghosts, pellets, score, and levels.

CS-107 Introduction to Programming at EPFL.
